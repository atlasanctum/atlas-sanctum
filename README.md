# 🏛 Repository Structure

```text
atlas-sanctum/
│
├── apps/                    # Deployable applications
│   ├── dashboard/           # Primary platform dashboard
│   ├── marketplace/         # Regenerative credit marketplace
│   ├── governance/          # DAO governance studio
│   └── mobile/              # Field agent mobile app
│
├── services/                # Backend microservices
│   ├── ai/                  # AI orchestration + GraphQL schema
│   ├── blockchain/          # On-chain anchoring + smart contracts
│   ├── analytics/           # CQRS read models + time-series
│   ├── identity/            # DID + verifiable credentials
│   └── payments/            # Regenerative credit payments
│
├── packages/                # Shared internal packages
│   ├── sdk/                 # @atlas-sanctum/sdk — public client SDK
│   ├── ui/                  # Shared component library
│   ├── shared/              # Utilities, constants, validation
│   └── config/              # Shared tooling configs
│
├── src/                     # Frontend application (React + Vite)
│   ├── components/
│   ├── pages/
│   ├── sanctum-ai/          # 10-layer AI type system
│   └── sanctum/             # Covenant Code (constitutional OS)
│
├── backend/                 # Node.js API server
│   └── src/
│       ├── routes/          # REST API routes (open)
│       └── types/           # Type contracts (open)
│
├── chain/                   # Cosmos SDK blockchain
│   └── proto/               # gRPC protocol definitions (open)
│
├── infrastructure/
│   ├── kubernetes/          # K8s manifests
│   ├── terraform/           # IaC (variables only — state is private)
│   └── docker/              # Docker configs
│
├── datasets/                # Open environmental, social, economic data
├── research/                # Open research: climate, governance, indigenous
├── documentation/           # Extended docs (mirrors docs/)
├── examples/                # Runnable SDK and integration examples
├── tests/                   # Unit, integration, and E2E test suites
├── docs/                    # Architecture decisions, API contracts, ADRs
└── supabase/                # Database migrations + edge functions
```

# ⚙ Technology Stack

## Frontend

- React 18
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- Three.js (globe visualizations)

## Backend

- Node.js (Express — primary API)
- Python (AI/ML services, Earth2Studio)
- Go (Cosmos SDK blockchain)
- Rust (planned — ZK proof generation)

## AI

- OpenAI / Anthropic (LLM providers with circuit-breaker fallback)
- Earth2Studio (NVIDIA — climate AI)
- Vector Databases (Weaviate)
- LangGraph (planned — agent orchestration)
- PyTorch / TensorFlow (planned — custom model training)

## Blockchain

- Cosmos SDK (sanctum-1 — native chain)
- Ethereum / Polygon (smart contracts, carbon credits)
- IPFS (decentralized storage)
- Chainlink (planned — oracle network)

## Cloud

- AWS
- Azure
- Google Cloud
- Kubernetes
- Docker

## Databases

- PostgreSQL + Supabase (primary — auth, RLS, realtime)
- Redis (caching, sessions, rate limiting)
- Neo4j (planned — knowledge graph)
- ClickHouse (planned — analytics time-series)
- InfluxDB (planned — IoT sensor streams)

## Observability

- Prometheus
- Grafana
- OpenTelemetry
